# Как запустить бота на Railway (работает 24/7)

## Шаг 1. Создай аккаунт
Зайди на https://railway.app и зарегистрируйся (можно через GitHub-аккаунт,
если есть, или через email).

## Шаг 2. Загрузи проект
Есть два способа — выбери, что проще:

**Способ А (без GitHub, самый простой):**
1. В Railway нажми "New Project" → "Empty Project"
2. Внутри проекта нажми "+ New" → "Empty Service"
3. Открой вкладку "Settings" этого сервиса → найди раздел "Source" →
   там будет возможность загрузить файлы (Deploy from local files) —
   загрузи все 3 файла: `bot.py`, `requirements.txt`, `Procfile`

**Способ Б (через GitHub, если есть аккаунт):**
1. Создай новый репозиторий на GitHub, загрузи туда `bot.py`,
   `requirements.txt`, `Procfile`
2. В Railway: "New Project" → "Deploy from GitHub repo" → выбери репозиторий

## Шаг 3. Добавь токен бота
1. В настройках сервиса найди вкладку "Variables"
2. Добавь переменную:
   - Имя: `BOT_TOKEN`
   - Значение: токен, который тебе дал BotFather
3. Сохрани

## Шаг 4. Запусти
Railway сам установит библиотеки и запустит бота после сохранения
переменной. Через минуту-две зайди в Telegram и напиши боту `/start` —
он должен ответить.

## Если что-то не работает
Открой вкладку "Deployments" → там будут логи (что происходило при
запуске) — можешь скопировать текст ошибки и прислать мне, разберём.
